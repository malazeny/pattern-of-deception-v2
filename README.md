My name is Malaz Elbadri and I go to Parsons School of Design fulltime. I created this project while studying abroad at UAL where we
were tasked to create some sort of Data Visualization. This is how I came to create this project "Patterns of Deception". Patterns of Deception 
is a scrollytelling website that explores and visualizes the 30,573 false and misleading claims made by Donald Trump during his first presidency
(2017–2021), using data from the Washington Post Fact Checker database. 

The central argument of this project was to showcase that these false and misleading claims were not just random but an actual system within his 
presidency. The same four narratives kept coming up over and over again across speeches, tweets, press conferences, and interviews. The border wall. 
A stolen election. China as the origin of COVID-19. The greatest economy in history.

The main aspects of my project are the dot visualization, the timeline, and the interactive machine. The dot visualization shwocases 1,000 claims
sas individual dots that reorganise by topic, source type, and repeated idea as you scroll through. The timeline is a a stacked bar chart built 
with D3.js showing all 30,573 claims plotted month by month across the full four years. Lastely, the interactive machine is an interactive filter 
letting you search and browse the archive by topic, source, and repeated idea

How to run it: 
1. install dependencies: pip install flask
2. run: python app.py
3. open: http://localhost:8000

Data source
Washington Post Fact Checker Trump Claims Database
Kessler, G., Rizzo, S. and Kelly, M. (2021)
https://www.washingtonpost.com/graphics/politics/trump-claims-database/
